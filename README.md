A to do list ASP.net/Blazor webapp Based on the tutorials at [asp.net](asp.net)!

## How to run
1. Clone the repository
2. Open Visual Studio Code and select File > Open Folder
3. Select the repository
4. Click run
5. Open http://localhost:5002/todos-ui in your favorite web browser
6. Have fun
